## 3. 真实 Agent 测试如何记录

使用 [端到端验收手册](AGENT_ACCEPTANCE.md)，按客户端与版本分别记录 L1–L5：文件安装、Skill 自动发现、原生调用、Prompt 初始化和安全回归。

允许状态：**通过、失败、阻塞、未测试**。仅有 CI 文件安装检查时，应明确标记为“客户端端到端：未测试”。

请勿将真实账号、密钥、生产项目或未经脱敏的对话日志提交到公开仓库。

## 4. 后续开发与版本发布约束

- `main` 已启用 [分支保护](MAINTENANCE.md)，后续变更统一走开发分支与 PR；不能直接推送 `main` 或绕过 CI。
- 一次 PR 聚焦一个目的，保持必要的中英文文档一致，填写实际验证与风险。
- `VERSION` 目前保留 `V1.1`，本清单为 V1.2 的**待验收开发计划**，不代表新的稳定版本。
- V1.2 不含“所有 Agent 客户端已验证”之类未经真实测试支持的声明。若部分客户端最终仍受限，须在发布说明中透明标注并由维护者决定是否接受风险。
