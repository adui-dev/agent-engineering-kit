# 🎉 Agent Engineering Kit V1.0 — 首个正式版本

Agent Engineering Kit 是一套**跨技术栈、可持续维护**的 AI Agent 工程化开发套件，适用于全新项目、已有项目和 Monorepo。本次发布提供可直接复用的中文初始化 Prompt、Skills 及轻量质量检查。

## ✨ 主要能力

- **八大核心工程资产**：AGENTS、REQUIREMENTS、SDD、ARCHITECTURE、PROJECT_CONTEXT、CODEBASE_MAP、Skills、Harness。
- **统一 Agent 协作规范**：项目现状识别、最小改动、文档维护、测试验证与交付标准。
- **架构与文档一致性**：按需建立 ADR、Documentation Validation。
- **8 项 Git/GitHub Skills**：覆盖 Conventional Commits、GitHub Issues、Pull Requests、GitHub Actions 工作流说明、安全加固和效率优化。
- **工程质量保障**：Python 标准库校验脚本、7 个单元测试和 GitHub Actions 质量检查。
- **中文工程协作**：Emoji + 中文 Conventional Commits；保留第三方 Skills 的原始来源和许可证。

## 🚀 快速开始

1. 在 AI 编程工具中打开需要初始化的**目标项目**。
2. 复制 [通用项目初始化 Prompt V1.0](https://github.com/adui-dev/agent-engineering-kit/blob/v1.0.0/prompts/project-initialization.zh-CN.md) 并交给能够访问目标仓库的 Agent。
3. 要求 Agent 先检查真实代码和配置，再按需生成工程资产和执行检查。
4. 审核实际变更、验证结果及尚未确认事项。

复制 Prompt 不等于自动完成初始化。目标 Agent 需要具备相应文件操作和运行权限。

## ⚠️ 已知限制

- 不同 AI 编程工具的 Skills 自动发现能力和外部操作权限需要分别验证。
- 一项基于规格创建 PR 的 Skill 使用已被上游移除的历史版本；详见 Skills 索引。
- 静态文档质量检查不等于全面业务测试、工具兼容验证或安全审计。
- 本仓库不是业务应用，也不包含可直接部署的后端服务。
