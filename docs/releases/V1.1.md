# 🌐 Agent Engineering Kit V1.1 — 双语文档与完整英文初始化 Prompt

**V1.1** 是继首个正式版本 V1.0 后的增量更新，重点提升面向国际开发者的可用性与文档维护质量。本次没有改变工具包的技术栈无关定位，仍然遵循最小改动和真实验证原则。

## ✨ 本次更新

- **完整英文初始化 Prompt**：新增 [English Project Initialization Prompt](https://github.com/adui-dev/agent-engineering-kit/blob/v1.1.0/prompts/project-initialization.en.md)，与中文版对应，涵盖全部 **16 个主章节**和 **8 类核心工程资产**。
- **双语快速入门**：优化 [中文 README](https://github.com/adui-dev/agent-engineering-kit/blob/v1.1.0/README.md)，新增 [English README](https://github.com/adui-dev/agent-engineering-kit/blob/v1.1.0/README.en.md)，覆盖项目定位、三步使用、Skills、质量检查与发布信息。
- **语言切换**：中英文 README、Prompt 均支持相互跳转，减少海外使用者查找资料的成本。
- **持续集成检查**：质量校验覆盖双语文档版本一致性、相对链接、Prompt 主章节与资产章节结构；单元测试扩展至 **15 项**。
- **维护规范**：补充双语内容同步规则及验证要求，保持中文 Emoji Conventional Commits 和第三方 Skills 的许可声明。

## 🚀 如何使用

1. 在 AI 编程工具中打开你需要初始化的**目标项目工作区**。
2. 选择 [中文初始化 Prompt](https://github.com/adui-dev/agent-engineering-kit/blob/v1.1.0/prompts/project-initialization.zh-CN.md) 或 [English Prompt](https://github.com/adui-dev/agent-engineering-kit/blob/v1.1.0/prompts/project-initialization.en.md)，复制全文给具备仓库访问权限的 Agent。
3. 让 Agent 先分析实际项目，再按需生成或完善 AGENTS、REQUIREMENTS、SDD、ARCHITECTURE、PROJECT_CONTEXT、CODEBASE_MAP、Skills 和 Harness。
4. 核对真实代码修改、测试执行结果、文档更新及待确认事项。

## ⚠️ 已知限制

- 静态校验可以检查文档结构，但**不能保证两种语言的语义完全一致**，仍需人工审阅重要变更。
- 各 AI 编程工具对于 Skills 发现、文件写入及外部服务操作的支持不同，需根据实际环境验证。
- 本仓库只提供工程指令和规范，不会仅因复制 Prompt 而自动部署或运行某个业务系统。
